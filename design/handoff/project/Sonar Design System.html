The Sonar design system

The tokens, type, color and components behind the Sonar apps. Calm, cool-neutral, dark-first — with two semantic accents that always mean the same thing: cyan for nearby / Bluetooth and indigo for internet, plus gold reserved for money.

Dark-first, light supported Figtree + IBM Plex Mono Transport-colored UI Click any swatch to copy
01

Principles

Every visual decision serves clarity and trust. The interface stays quiet so the meaningful signals stand out.

Color carries meaning

Accents aren't decoration. Cyan = reachable over Bluetooth, indigo = over the internet, gold = money, green = verified/online. Never mix these roles.

Dark-first, calm surfaces

Near-black cool neutrals, hairline borders, soft elevation. Light mode is a faithful mirror, not an afterthought.

Monospace for truth

Keys, fingerprints, geohashes and offers render in IBM Plex Mono — the technical bits look technical, everything else stays human.

One radius language

Bubbles, cards and sheets share a rounded, friendly radius scale. Tightened opposite-corner on chat bubbles gives direction.
